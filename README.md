# Number Guessing Game (1–15)

A simple Python number guessing game. The program picks a random secret number between **1 and 15**, and the player has a limited number of attempts to guess it. A text menu lets you start the game or exit.

## Features
- Random secret number between **1** and **15**
- Input validation (handles non-numeric input)
- Feedback after each guess:
  - **Too high!**
  - **Too low!**
  - **You got it right!**
- Maximum attempts (9 guesses)
- Simple menu:
  - Start the game
  - Exit

## How to play
1. Run the program.
2. Enter your name when prompted.
3. Choose `1` to start or `2` to exit.
4. Type your guesses.
5. You’ll receive feedback until you guess correctly or you run out of attempts.

## Requirements
- Python 3.x
